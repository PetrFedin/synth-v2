# Syntha · Omni Orange 2

Статус: проект (предложение). В репозитории действует ODS v1 (`public/omnidata-v14-role-system.css`, токены `--ods-*`). Этот файл не заменяет `ARCHITECTURE.md` §10 до тех пор, пока изменения не внесены туда в том же PR (правило `AGENTS.md`).

## 1. Visual Theme & Atmosphere

Рабочий инструмент для людей, которые целый день сидят в таблицах: светло-серый фон, белые карточки, тонкие линии, оранжевый только там, где нужно действие или текущее место. Спокойно, плотно, без декора. Состав: сайдбар тёмный (`#303640`), рабочая зона светлая. Оранжевая палитра Syntha сохранена по решению владельца.

Принципы: один смысл на экран; одна главная кнопка; линии вместо теней; цвет никогда не единственный носитель смысла; плотность таблиц ценнее воздуха.

## 3. Typography Rules
> Примечание: шрифт Inter первым в стеке стоит только в `public/styles.css`; в токенах слоя `omnidata-v14-role-system.css` (подключается последним) стоит Arial, поэтому реальный шрифт зависит от слоя. Предложение перейти на Inter/Onest относится к целевому состоянию.


- Семейство: **Inter** (кириллица, табличные цифры), запасной Onest, затем `system-ui`, Arial. Файлы woff2 хостить самим (не с чужого CDN); подключать одним `@font-face` в слое токенов. Подбор Inter vs Onest — в `docs/business/03-design-and-ui-analysis.md`, п. 4; Onest на `tnum` и ширину не проверен.
- Для запасного шрифта задать `size-adjust`, чтобы переход не двигал таблицы.
- Шкала: 11 (подписи, шапка таблицы) · 12 (кнопки, поля, ячейки) · 13 (основной текст) · 16 (подзаголовок) · 22 (H1). Функциональный текст не мельче 11 px; значения 8–10.5 px, которые есть в CSS сейчас, — долг, не образец.
- Веса: 400 / 500 / 600; 700 только h3/h4 и шапка таблицы. Заголовки 600.
- Цифры в таблицах, деньгах и количествах: `font-feature-settings: "tnum" 1;` выравнивание вправо; валюта рядом с кодом.
- Шапка таблицы: 11 px, uppercase, `letter-spacing: .04em` (сейчас до .08em), цвет `textSoft`.
- Не более одного шрифта (плюс моноширинный для токенов и ID).

## 4. Component Stylings

**Кнопка** (высота 34, на сенсорных режимах 44; padding-x 12; радиус md 6; шрифт 12/600; рамка 1px):

| Состояние | Вид |
|---|---|
| Основная default | заливка `accent`, текст `onAccent`, рамка `accent` |
| Основная hover | заливка `accentHover` |
| Основная pressed | заливка `accentPressed` |
| Вторичная default | белый фон, рамка `borderStrong`, текст `textSoft` |
| Вторичная hover | фон `surfaceHover`, рамка `accent`, текст `accentText` |
| Опасная | белый фон, рамка `dangerBorder`, текст `danger`; hover — фон `dangerBg` |
| Призрачная | без рамки и фона, текст `textSoft`; hover — `surfaceSoft` |
| Focus-visible (все) | контур 2 px `focus`, отступ 2 px |
| Disabled | цвета `textMuted` на `surfaceSoft`, рамка `border`, курсор `not-allowed` (вместо opacity .45) |
| Loading | текст сохраняется, слева иконка-индикатор, `aria-busy="true"`, повторный клик блокируется |

Одна основная кнопка на экран. Иконочная кнопка: квадрат 34 (44 на сенсорных), обязательно `aria-label` на RU/EN.

**Поле** (text/select/textarea): высота 34, padding-x 10, радиус 4, рамка 1px `borderStrong`, шрифт 12/500; фокус — рамка `accent` + кольцо 2 px `rgba(255,91,34,.18)` + контур `focus` не отключать; ошибка — рамка `danger`, текст ошибки под полем 12 px с иконкой; textarea min 88. Чекбокс/радио 16×16, `accent-color` = `accent`.

**Таблица**: строка 42, шапка 36 sticky, граница снизу 1px `border`, строки без вертикальных линий, hover `surfaceHover`, выбранная `surfaceSelected`, числа вправо и `tnum`, горизонтальный скролл у контейнера, min-width 720.

**Карточка**: фон `surface`, рамка 1px `border`, радиус lg 8, padding 16, тень shadow1 или без тени.

**Статус**: пилюля 999, min-height 22, 11–12 px/600, фон `*Bg`, рамка `*Border`, текст цветом статуса + иконка или слово (цвет не единственный носитель).

**Вкладки**: текст `textSoft`, активная — текст `text` и нижняя полоса 2 px `accent`; не красить активный текст в `accent` (контраст).

**Инспектор**: ширина 360, не перекрывает таблицу.

**Состояния экрана**: *Пусто* — иконка 24, одна фраза, одно действие. *Загрузка* — скелетон строк таблицы высотой 42; спиннер только внутри кнопки. *Ошибка* — сообщение понятным языком + «Повторить»; для 409 — «Данные изменились, обновить». *Нет прав* — состояние секции, не ошибка (так в `ARCHITECTURE.md` §4.4).

**Иконки**: один набор inline-SVG, сетка 24, линия 1,5 px, `currentColor`; символы `× ‹ › •••` как иконки не использовать. Конкретный набор выбрать и записать в `ARCHITECTURE.md` (лицензия и минимум зависимостей).

## 5. Layout Principles

Шаг 4 · 8 · 12 · 16 · 24 · 32. Максимальная ширина контента 1760. Сайдбар 232 / 208 (компакт) / 68 (иконки). Верхняя панель ≥50. Поля и отступы кратны 4. Списки действий в шапке экрана справа; главное действие правее остальных. Цепочка «кампания → коллекция → шоурум → заказ → сделка» и статус сущности всегда видны в шапке экрана.

## 6. Depth & Elevation

| Уровень | Значение | Где |
|---|---|---|
| 0 | нет | таблицы, поля, кнопки |
| shadow1 | `0 1px 2px rgba(34,40,49,.06)` | карточки, фильтры |
| shadow2 | `0 8px 24px rgba(34,40,49,.12)` | меню, поповеры, панель фильтров (сейчас `0 10px 30px rgba(15,20,26,.14)`) |
| shadow3 | `0 24px 64px rgba(34,40,49,.24)` | модальные окна (сейчас `0 24px 80px` в `bom.css`) |

Основная глубина создаётся линией 1px и сменой фона, не тенью. Затемнение под модалкой `rgba(34,40,49,.5)`.

## 7. Do's and Don'ts

**Можно**: серый фон и белые карточки; оранжевая заливка у главной кнопки; `accentText` для оранжевого текста; тонкие границы 1px; цифры `tnum`; одно действие акцентом; иконка и слово рядом с цветом статуса.

**Нельзя**: белый текст на `#FF5B22` (3,10:1); оранжевый мелкий текст на белом или сером (`#FF5B22` на `#F2F4F5` — 2,81:1); оранжевый фон больших областей; фиолетовый и любые hex вне токенов; тяжёлые рамки 2px+ и двойные рамки; больше двух уровней теней в одной области; шрифт меньше 11 px; новые файлы `omnidata-vNN.css/js` со своими токенами (правило `AGENTS.md`); локальные визуальные диалекты на экране; кнопка без обработчика (правило `AGENTS.md`).

## 8. Responsive Behavior

Режимы (реализованы в `viewport-mode.js`): монитор — основная среда, плотные таблицы и инспектор рядом; планшет (≈701–1080 px) — шоурум и подборки, цели касания 44; телефон (≤700 px) — просмотр и подтверждения, таблицы с горизонтальным скроллом контейнера, инспектор отдельным экраном. Основные действия на сенсорных режимах ≥44×44. Не терять строки таблицы за обрезкой: скролл у контейнера, не у страницы. Уважать `prefers-reduced-motion` (сейчас обработан только в `omnidata-v14-role-system.css`). Переходы 120–160 мс, только цвет/фон/рамка.

## 9. Agent Prompt Guide

- Перед изменением интерфейса прочитай этот файл и `ARCHITECTURE.md` §10; значения токенов — только отсюда.
- Новый UI: используй семь ролей ODS (`table`, `filterbar`, `card`, `status`, `inspector`, `button`, `field`) и `data-ods-part`; не создавай `omnidata-vNN` и локальные стили.
- Все тексты — через `public/modules/i18n-runtime.js`, RU и EN.
- Проверка перед сдачей: контраст AA (текст 4,5:1; граница поля 3:1 по возможности), фокус виден, цели касания 44 на планшете/телефоне, текст ≥11 px, одна основная кнопка, состояния пусто/загрузка/ошибка, `tnum` в числах, `npm run validate:ui`, `validate:design-system`, `validate:ods-boundaries`, `validate:i18n`.
- Любое изменение токенов — в том же PR обновить `ARCHITECTURE.md` §10 и приложить скриншоты до/после.
- Примеры запросов: «Сделай таблицу заказов: плотные строки 42 px, числа с tnum, основная кнопка “Подтвердить” одна, статус пилюлей с иконкой»; «Добавь состояние ошибки для списка BOM с кнопкой Повторить».
- Движение — по навыку `design-motion-principles`, всегда с `prefers-reduced-motion`.

## Что осталось неподтверждённым
- Все значения «новое» (onAccent, accentText, focus, accentPressed, тени; радиусы предложены 4/6/8, а в текущем слое `--ods-radius-*` они 3/5/8) не показаны на экране и не одобрены владельцем; контрасты посчитаны по формуле WCAG, не измерены в браузере.
- Inter выбран по общей известности, не по тесту на плотных таблицах; Onest не проверен на табличные цифры.
- Реальные отличия живого интерфейса от токенов (слои v7–v14, фиолетовый `bom.css`).
- Набор иконок не выбран.
