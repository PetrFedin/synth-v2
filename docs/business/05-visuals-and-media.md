## 5. Правила для изображений (предложение, применить при добавлении хранилища)

| Правило | Значение | Почему |
|---|---|---|
| Форматы | WebP или AVIF для фото, SVG только для своих знаков, PNG для скриншотов; JPEG допустим как входной | вес и совместимость; входной список инжиниринга уже включает jpeg/png/webp/svg |
| Размеры | оригинал ≤ 20 МБ (как в инжиниринге), плюс производные 220, 480, 960, 1600 px по длинной стороне | сетка подборки показывает 220 px |
| Ленивая загрузка | `loading="lazy"` и `decoding="async"` везде кроме первого экрана | уже так в коде |
| `alt` | название модели и цвет; для декоративных `alt=""`; для иконок `aria-hidden` | доступность |
| Права | запись об авторе и сроке лицензии в `payload` медиа; бренд подтверждает права | платформа не хранит файл, но отвечает за витрину |
| Персональные данные | модели на фото: согласие на съёмку и публикацию хранить у бренда; EXIF (геометка, камера) удалять при загрузке; лица не распознавать | 152-ФЗ (см. `01`, п. 13), не юридическая консультация |
| Проверка загрузки | сигнатура, расширение, лимит, SHA-256, проверка SVG на скрипты | уже реализовано для инжиниринга (`source-upload.mjs`), перенести на все загрузки |
| Вес страницы | цель: первый экран шоурума ≤ 1,5 МБ изображений | гипотеза, измерить |

## 6. Находки по визуальной части (подтверждены кодом)

1. **Лукбук и CSP противоречат.** Домен принимает только `https://` (`showroom-looks/public.mjs`:80), интерфейс отфильтровывает всё, кроме того же происхождения и `data:image/` (`dom-1.js`:113–121), а CSP не допускает внешние картинки (`static-handler.mjs`:287). Результат: внешние ссылки на фото не отображаются; для ссылки на тот же хост нужен `https`, что для локальной разработки (`http`) тоже даёт пустую картинку. Проверка: чтением трёх фрагментов; в браузере не воспроизводилось.
2. **Нет файлового хранилища для медиа**, об этом прямо сказано в комментарии кода (`showroom-looks/public.mjs`:75–78). Хранилище байтов есть только у инжиниринга.
3. **Нет favicon и OG**: `index.html` не содержит соответствующих тегов (`public/index.html`:1–10).
4. **Шрифт не загружается**: заявлен Inter, файла нет.
5. **Графиков и рендера чертежа нет**, хотя данные для чертежа (объекты контура, якоря измерения) в БД есть.
