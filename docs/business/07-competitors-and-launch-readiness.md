# Syntha V2: конкуренты и готовность к запуску

Дата: 2026-10-15. Состояние Syntha: чтение клона опубликованной версии (код не запускался). Конкуренты: веб-поиск 2026-10-15, страницы вендоров и агрегаторов (Capterra, FitGap, G2, GetApp), плюс внутренние документы репозитория. Маркетинговые тезисы вендоров не независимая оценка; цены агрегаторов часто не равны прайсу. Обозначения: ● есть, ◐ частично, ○ нет, ? не проверено.

## 3. Где конкуренты сильнее

| Область | Конкурент | Почему важно |
|---|---|---|
| Сеть байеров | JOOR, NuORDER, Brandboom | у Syntha 0 готовых покупателей; «ещё одна витрина» без сети проигрывает |
| Зрелость и отзывы | Centra (G2 4,8/5, 69 отзывов [5]), NuORDER (Capterra 4,2/5, 40 отзывов [2]) | у Syntha пока нет платящих клиентов (`01`) |
| Интеграции | NuORDER (120+), Centra (OMS/ERP), Centric | у Syntha нет 1С, ЭДО, POS; только вебхук и скрипт курсов |
| Платежи | JOOR | у Syntha платежей нет |
| Готовые российские внедрения PLM | Omnidata.PLM, Centric у Limé | клиенты уже есть и привыкли к их терминам |
| Простота входа и цена | Brandboom | $50–149 в месяц против гипотетических 15 000–90 000 ₽ |

## 4. Что проверить руками перед показом заказчику

Проверка выполняется человеком на отдельной тестовой среде (не боевой). Столбец «Результат» заполняется при проверке.

| № | Что проверить | Шаги | Ожидание | Результат |
|---|---|---|---|---|
| 1 | Вход и выход | войти, обновить страницу, выйти | сессия живёт до выхода, после выхода токена нет | |
| 2 | Цепочка до сделки | кампания → открыть → коллекция → добавить модель → опубликовать → шоурум → открыть → поделиться → принять от имени магазина → цикл → подборка → заказ → принять обеими сторонами → прикрепить → «Открыть DealSpace» | сделка открыта, в календаре две записи | |
| 3 | Запреты | попробовать отправить пустую подборку, смешать валюты, принять условия одной стороной, закрыть цикл с прикреплённым заказом | отказы с понятным текстом | |
| 4 | Двойной клик | быстро нажать «Прикрепить» дважды | один снимок, одна сделка | |
| 5 | Конкурентность | открыть заказ в двух окнах, изменить условия в обоих | второй получает «данные изменились» (409) | |
| 6 | Роли | зайти под sales, production, quality, finance, buyer, viewer; сверить кнопки с матрицей `08` | лишних кнопок нет, серверный отказ при ручной попытке | |
| 7 | Изоляция | две пары «бренд—магазин»; под вторым магазином попытаться открыть чужой шоурум и заказ по id | отказ или пустой ответ | |
| 8 | Скрытие себестоимости | под buyer и viewer открыть позицию экономики и ответы API | полей cost/margin нет | |
| 9 | Фото лукбука | добавить образ с https-картинкой чужого домена и с адресом своего хоста | понять, что показывается (ожидается дефект, `05` п. 6) | |
| 10 | Загрузка файла инжиниринга | pdf, xlsx, csv, png, файл с неверным расширением, файл >20 МБ | допустимые принимаются, остальные отказ | |
| 11 | ИИ-разбор | запуск анализа без квалифицированной модели | отказ с сообщением, ничего не записано в мастер-данные | |
| 12 | Приглашение сотрудника | пригласить, передать токен, принять, сменить роль, отключить | письма нет (известный GAP), токен работает | |
| 13 | Пересчёт при правке изделия | изменить опубликованную версию материала/измерения и посмотреть план пересчёта | запись ChangeCase/плана; ручные шаги в списке «Ожидает действия» отсутствуют (B2) | |
| 14 | Мобильный и планшет | `?viewport=phone` и `?viewport=tablet` | таблицы с прокруткой внутри контейнера, цели касания не меньше 44 px | |
| 15 | Языки | переключить RU/EN на каждом проверяемом экране | нет смеси языков | |
| 16 | Резервная копия | снять копию БД и восстановить на пустой экземпляр | заказ и снимки совпадают | |
| 17 | Производительность | загрузить рабочее место с 500+ строками | страницы по курсору, без зависаний | |
| 18 | Ошибки сети | отключить сеть во время сохранения матрицы | сообщение, повтор с тем же ключом без дублей | |
