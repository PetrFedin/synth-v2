            12. Расхождения с DESIGN.md и рекомендация по теме

            • textMuted #69727D → #626B76: на сером фоне #F2F4F5 было 4,42:1 (не проходит AA для текста до 14 px), стало 4,90:1.
            • accentHover #E84B15 → #FF7444: тёмный текст #1B1F23 на #E84B15 давал 4,30:1 (не проходит). Наведение теперь светлее заливки, 6,18:1.
            • accentPressed #D43F0E (3,57:1 с тёмным текстом) заменён на заливку accent с внутренней рамкой 1 px тёмного цвета.
            • borderControl #858E98 добавлен для границ полей, чипов и переключателей: borderStrong #C7CDD3 даёт только 1,60:1 на белом (нужно 3:1 по WCAG 1.4.11). Для карточек и разделителей остаются border и borderStrong.
            • xs 11 px → 12 px: по заданию текст не мельче 12 px (в DESIGN.md 11).
            • Добавлены токены боковой панели: sidebarText #E6E9ED (9,98:1 на #303640) и sidebarMuted #B4BBC4 (6,28:1).
            • Все изменения нужно перенести в DESIGN.md и ARCHITECTURE.md §10 в одном PR после согласия владельца: пока это предложение.

            Тёмная тема

            В проекте тёмной темы нет (color-scheme: light в public/index.html, prefers-color-scheme в CSS не найден). Здесь она не выдумывается. Рекомендация: вводить только после свода слоёв omnidata-v3…v14 на токены, начиная с переменных --ods-color-*; взять сайдбар #303640 как отправную поверхность, пересчитать пары таблицы контраста (скрипт выше работает на любой теме) и проверить плотные таблицы на пяти ключевых экранах.
