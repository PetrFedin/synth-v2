# MDM Changelog

All notable master-data catalog changes are recorded here. Database migrations remain immutable after application.

## 0.1.0 - 2026-08-05

- Established bilingual MDM repository structure.
- Added governed reference-record, attribute and metric schemas.
- Added complete domain inventory for fashion development, sourcing, production, wholesale, CRM, analytics and integrations.
- Added initial product attribute sets and cross-functional metric catalog.
- Added PostgreSQL MDM core with effective dating, approvals, immutable codes, audit versions and transaction snapshots.
- Added official-source registry, deterministic validation and scheduled source-change detection.
